Tramos de bono (sobre la meta total)

La meta es la venta neta de todas las vendedoras sumada. Al llegar a un tramo, cada vendedora gana ese % de su propia venta neta. No es acumulable: se paga solo el tramo más alto alcanzado.

Instalar y usar sin conexión

Una vez abierta con internet la primera vez, la app queda guardada en el dispositivo y funciona sin conexión (ventas, metas, filtros, fotos, Excel y respaldos por archivo). Solo el respaldo en GitHub necesita internet.

Android (Chrome): toca Instalar app en la barra, o el menú ⋮ → Instalar aplicación.
iPhone (Safari): botón Compartir → Agregar a pantalla de inicio. Instálala antes de cargar datos y úsala siempre desde su ícono: en iPhone la app instalada guarda sus datos aparte de Safari.

Los datos viven en este dispositivo: haz un respaldo de vez en cuando (Respaldos).

Recibir / actualizar desde un enlace

Pega la dirección Raw de un respaldo publicado en GitHub (empieza con https://raw.githubusercontent.com/…). Queda guardada: después basta con apretar Actualizar en la barra superior.

Publicar mi respaldo para otros

El cifrado usa la contraseña de arriba (mínimo 8 caracteres).

Cómo subirlo a GitHub y compartir el enlace
  1. Descarga el respaldo con uno de los botones.
  2. En GitHub abre tu repositorio → Add file → Upload files → arrastra el archivo → Commit changes. Para publicar una versión nueva, sube otra vez un archivo con el mismo nombre: reemplaza al anterior.
  3. Abre el archivo en GitHub → botón Raw → copia la dirección.
  4. Pásasela a tus compañeros: la pegan en "Recibir / actualizar desde un enlace" y desde entonces solo aprietan Actualizar. Mientras el archivo conserve el nombre, el enlace no cambia.

El repositorio debe ser público para que el enlace funcione sin clave. Cualquiera que tenga el enlace podrá bajar el archivo: cífralo y usa una contraseña larga. Si el navegador agrega "(1)" al nombre al descargar, renómbralo antes de subirlo.
